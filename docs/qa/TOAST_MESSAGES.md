# 토스트 / 에러 메시지 문구

QA 처리 시 참고하는 토스트 메시지 및 입력 에러 메시지 문구 기준표입니다. (기획 전달 문구 그대로 기록)

관련 QA: [QA-015](QA_LIST.md) (서류 첨부 > 공고 링크 공백 입력 에러)

## 통합 공고 탐색

- 칸반 보드 등록 > 공고 중복 등록 시
  - "이미 등록된 공고예요."
- 칸반 보드 등록 > 지원 현황 추가 시
  - "지원 현황에 추가되었어요."

## 지원 현황 관리

- 지원 현황 추가 > 전형 단계 내 (+) 버튼을 통한 지원 현황 추가 시
  - "지원 현황이 추가되었어요."
- 지원 현황 추가 > 예외 메시지
  - **[회사명]**
    - 입력하지 않음, 공백만 입력: "회사명을 입력해 주세요."
    - 한 글자 입력: "2자 이상 입력해 주세요."
    - 51자 이상 입력: "50자를 초과하여 입력할 수 없어요."
    - 특수문자만 입력 (예: !!!, @@@), 이모지 입력: "특수문자나 이모지는 입력할 수 없어요."
    - 자음/모음으로만 입력: "올바른 단어 형태로 입력해 주세요."
  - **[공고명]**
    - 입력하지 않음, 공백만 입력: "공고명을 입력해 주세요."
    - 한 글자 입력: "2자 이상 입력해 주세요."
    - 101자 이상 입력: "100자를 초과하여 입력할 수 없어요."
    - 특수문자만 입력 (예: !!!, @@@), 이모지 입력: "특수문자나 이모지는 입력할 수 없어요."
    - 자음/모음으로만 입력: "올바른 단어 형태로 입력해 주세요."
  - **[공고 링크]**
    - 입력하지 않음, 공백만 입력: "공고 링크를 입력해 주세요."
    - URL 형식이 아님 (예: abcde): "올바른 URL 형식(https://...)으로 입력해 주세요."
    - 2049자 이상 입력: "2048자를 초과하여 입력할 수 없어요."
    - 이미 등록된 링크 입력: "이미 등록된 공고예요."
- 지원 현황 삭제 > 등록된 공고 카드 삭제 시
  - "지원 현황이 삭제되었어요."
- 전형 단계 추가 > 전형 단계 추가 시
  - "[OO] 단계가 추가되었어요."
- 전형 단계 추가 > 동일한 이름의 전형 단계 추가 시
  - "이미 존재하는 전형 단계 이름이에요."
- 전형 단계 추가 > 전형 단계 10개 초과 시
  - "전형 단계는 최대 10개까지 추가할 수 있어요."
- 전형 단계 수정
  - "전형 단계 이름이 수정되었어요."
- 전형 단계 수정 > 전형 단계에 잘못된 이름 입력 시
  - 입력하지 않음, 공백만 입력: "전형 단계 이름을 입력해 주세요."
  - 한 글자 입력: "2자 이상 입력해 주세요."
  - 21자 이상 입력: "20자를 초과하여 입력할 수 없어요."
  - 특수문자만 입력 (예: !!!, @@@), 이모지 입력: "특수문자나 이모지는 입력할 수 없어요."
  - 자음/모음으로만 입력: "올바른 단어 형태로 입력해 주세요."
  - 이미 등록된 전형 이름 입력: "이미 존재하는 전형 단계 이름이에요."
- 전형 단계 삭제 > 삭제하려는 단계에 공고 카드가 들어있을 시
  - "공고 카드가 남아있는 단계는 삭제할 수 없어요. 카드를 삭제 · 이동 후 다시 시도해 주세요."
- 지원 내역 수정
  - "수정 사항이 저장되었어요."

  - URL 형식이 아님 (예: abcde): "올바른 URL 형식(https://...)으로 입력해 주세요."
  - 2049자 이상 입력: "2048자를 초과하여 입력할 수 없어요."
