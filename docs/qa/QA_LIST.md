## QA 항목

### 우선순위: 상

#### [QA-004] 검색 시 띄어쓰기 유무와 무관하게 동일 키워드로 매칭되어야 함

- 기능명: 통합 공고 탐색
- 우선순위: 상
- 상태: 대기
- QA 내용: 검색창에 "채용공고"(붙여쓰기)로 검색하면 "채용 공고"(띄어쓰기)가 포함된 공고가 검색되지 않음
- 상세 내용:
  - AS-IS: 검색창에 "채용 공고"가 아닌 "채용공고"라고 검색했을 때, 해당 공고가 검색 결과에 노출되지 않는다.
  - TO-BE: 띄어쓰기 유무와 관계없이 동일한 키워드로 처리되어 해당 공고가 정상 노출되어야 한다.

### 우선순위: 중

#### [QA-001] 필터링 내 전체 초기화 버튼 추가

- 기능명: 통합 공고 탐색
- 우선순위: 중
- 상태: 대기
- QA 내용: 적용된 모든 필터 조건을 한 번에 초기화하는 버튼이 없음
- 상세 내용:
  - AS-IS: 적용된 모든 필터 조건을 초기화하려면 개별 필터 항목을 일일이 열어 각각 초기화 버튼을 클릭해야 하는 번거로움(조작 피로도)이 존재한다.
  - TO-BE: 필터링 버튼 그룹 좌측에 '전체 초기화' 버튼을 만들어, 단 한 번의 클릭으로 적용된 모든 필터 조건을 즉시 해제할 수 있도록 개선한다.
- 참고 이미지: -
- 비고: -

#### [QA-003] 페이지네이션 UI/UX 개선 (5단위 → 10단위 블록)

- 기능명: 통합 공고 탐색
- 우선순위: 중
- 상태: 대기
- QA 내용: 페이지네이션이 5페이지 단위 슬라이딩 방식이라 먼 페이지 이동 시 클릭 횟수가 과도함
- 상세 내용:
  - AS-IS: 현재 페이지네이션은 선택한 페이지를 중심으로 앞뒤 2페이지씩만 노출되는 '5페이지 단위 슬라이딩 방식'으로 구현되어 있다. 전체 데이터가 많을 경우 마지막 페이지나 먼 페이지로 이동하기 위한 클릭 횟수가 과도하게 늘어나 탐색 효율성이 떨어진다.
  - TO-BE: 화살표 버튼의 기능은 유지하되, 한 화면에 노출되는 페이지 단위를 5개에서 10개 블록(Chunk) 단위로 확장한다. 이전/다음 화살표를 누르면 1페이지씩 밀리는 것이 아니라 '1~10', '11~20'과 같이 10개 단위로 한 번에 건너뛸 수 있도록 변경한다.
- 참고 이미지: [images/QA-003-1.png](images/QA-003-1.png), [images/QA-003-2.png](images/QA-003-2.png)(AS-IS 5단위 예시) / [images/QA-003-3.png](images/QA-003-3.png), [images/QA-003-4.png](images/QA-003-4.png)(TO-BE 10단위 예시)
- 비고: -

### 우선순위: 하

#### [QA-002] 필터링 UI를 모달에서 드롭다운으로 개선

- 기능명: 통합 공고 탐색
- 우선순위: 하
- 상태: 대기
- QA 내용: 지역/직군·직무/경력 등 필터가 개별 모달로 열려 조작 depth가 늘어남
- 상세 내용:
  - AS-IS: 현재는 지역, 직군·직무, 경력 등 각 필터가 개별 모달(Modal) 창으로 제공된다. 여러 조건을 설정할 때마다 '모달 열기 → 닫기' 과정을 매번 반복해야 하는 번거로움(조작 Depth 증가)이 발생한다.
  - TO-BE: 모달 대신 드롭다운(Dropdown / Popover) 형태의 UI로 변경한다. 필터 항목을 누르는 즉시 하단에 관련 옵션 창이 나타나게 하여, 불필요한 창 닫기 과정 없이 빠르고 연속적인 필터링이 가능하도록 개선한다.
- 참고 이미지: [images/QA-002-1.png](images/QA-002-1.png)(AS-IS 지역 필터 모달) / [images/QA-002-2.png](images/QA-002-2.png), [images/QA-002-3.png](images/QA-002-3.png)(TO-BE 드롭다운 참고 예시)
- 비고: TO-BE 참고 이미지는 타 서비스 UI 참고 자료(다크 테마) — 실제 디자인 확정 전 참고용, Figma 스펙 확정 필요
