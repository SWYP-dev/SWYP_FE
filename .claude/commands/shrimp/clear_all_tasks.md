# /shirimp:clear_all_tasks

`mcp__shrimp-task-manager__clear_all_tasks` 도구를 호출한다. 미완료 작업을 모두 지우고 작업 목록을 초기화한다. **파괴적 작업이며 되돌릴 수 없다.** 완료된 작업은 초기화 전에 백업된다.

## 사용법

```
/shirimp:clear_all_tasks
```

인자는 받지 않는다 — 호출 전 반드시 사용자에게 확인을 받는다.

## 파라미터

- `confirm` (선택, boolean): 미완료 작업 전체 삭제(되돌릴 수 없음)에 대한 확인

## 동작

1. 이 커맨드가 호출되면 먼저 사용자에게 "미완료 작업을 모두 삭제하고 초기화하시겠습니까?"라고 명시적으로 재확인한다.
2. 사용자가 확실히 동의한 경우에만 `confirm: true`로 도구를 호출한다.

## 주의사항

- 사용자의 명시적 동의 없이 이 커맨드를 실행하지 않는다.
- 새로 시작하려는 의도가 실제로는 `selective` 업데이트(`/shirimp:split_tasks`)로 충분한 경우가 많다 — 정말 전체 초기화가 필요한지 먼저 확인한다.
