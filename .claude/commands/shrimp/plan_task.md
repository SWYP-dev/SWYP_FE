# /shirimp:plan_task

`mcp__shrimp-task-manager__plan_task` 도구를 호출한다. 작업을 계획하거나 복잡한 기능을 구성해야 할 때, 이 도구가 반환하는 단계별 지침을 따라 작업을 조직한다. 기존 작업을 참고해 이어서 계획할 수도 있다.

**중요 제약**: 모든 형태의 `추측`, `짐작`, `상상`은 엄격히 금지된다. 계획을 세우기 전에 사용 가능한 모든 도구(코드 읽기, 검색 등)를 사용해 `실제 정보`를 수집해야 한다.

## 사용법

```
/shirimp:plan_task $ARGUMENTS
```

`$ARGUMENTS`에는 계획하려는 작업에 대한 설명을 자유롭게 적는다 (예: "어드민 로그인 페이지 구현 계획 세워줘").

## 파라미터

- `description` (필수, 10자 이상): 작업 목표·배경·기대 결과를 포함한 완전하고 상세한 문제 설명
- `requirements` (선택): 특정 기술 요구사항, 비즈니스 제약, 품질 기준
- `existingTasksReference` (선택, boolean, 기본 false): 기존 작업을 조정/연속 계획의 기반으로 참고할지 여부

## 동작

1. `$ARGUMENTS`가 비어 있거나 10자 미만이면 사용자에게 작업 설명을 더 구체적으로 요청한다.
2. `description`을 `$ARGUMENTS` 기반으로 구성하고, 대화에서 파악된 기술 제약이 있으면 `requirements`에 채운다.
3. 기존 작업 목록을 이어서 조정하는 요청이면 `existingTasksReference: true`로 호출한다.
4. 도구가 반환하는 가이드를 그대로 따라 이후 단계(`analyze_task` 등)로 진행한다.

## 주의사항

- 이 도구 자체는 실제 코드를 작성하지 않는다 — 계획 프로세스의 시작점일 뿐이다.
