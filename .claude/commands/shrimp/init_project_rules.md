# /shirimp:init_project_rules

`mcp__shrimp-task-manager__init_project_rules` 도구를 호출한다. 프로젝트 표준 문서를 초기화한다. 사용자가 프로젝트 표준 문서 생성/초기화를 요청하거나, 기존 표준의 변경/갱신을 요청할 때 사용한다.

## 사용법

```
/shirimp:init_project_rules
```

인자는 받지 않는다.

## 동작

1. 도구를 호출하면 AI 에이전트 전용 운영 규칙 문서(`shrimp-rules.md`)를 프로젝트 루트에 작성하라는 가이드가 반환된다.
2. 가이드에 따라 프로젝트 폴더/파일을 재귀적으로 확인하고, 일반적인 개발 지식이 아닌 **프로젝트 고유 규칙**(어떤 파일을 참조/수정해야 하는지, 여러 파일 동시 수정이 필요한 경우 등)만 명령형으로 작성한다.
3. 이미 `shrimp-rules.md`가 있는 "갱신" 요청이면 기존 규칙을 최대한 유지하는 최소 변경 원칙을 따르되, 코드가 바뀌어 낡은 규칙은 수정/삭제하고 새로 필요한 규칙은 보완한다.

## 주의사항

- 이 프로젝트의 `CLAUDE.md`/`.claude/rules/*.md`가 이미 언어·커밋·브랜치·코드 스타일의 원본 규칙이므로, `shrimp-rules.md`는 그것과 중복하지 않고 실제 코드 구조에서 발견되는 AI 전용 판단 지점만 다룬다.
