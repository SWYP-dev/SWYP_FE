discription: git 푸쉬
---

커밋된 내용을 깃허브로 푸쉬해주고, PR 디스크립션을 작성한 뒤 실제로 PR까지 열어주세요.

- PR 디스크립션 양식은 `./CONTRIBUTING.md`와 `.github/PULL_REQUEST_TEMPLATE.md`를 참고해주세요.
- base 브랜치는 `CONTRIBUTING.md` 기준대로 반드시 `develop`으로 지정해주세요.
- `gh pr create`로 PR을 생성하고, 생성된 PR URL을 알려주세요.
- PR 머지는 여전히 사용자가 직접 진행하므로, 자동으로 머지하지 마세요.
